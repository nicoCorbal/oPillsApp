# oPills - Aplicación de Gestión de Medicamentos

**oPills** es una aplicación móvil desarrollada con React Native y Expo para la gestión y seguimiento de medicamentos. Permite a los usuarios registrar y controlar sus tratamientos, incluyendo dosis, horarios y descripciones detalladas.

## 🚀 Características

- 📱 Interfaz moderna y fácil de usar  
- 💊 Gestión completa de medicamentos  
- ⏰ Recordatorios y seguimiento de horarios  
- 📝 Descripciones detalladas  
- 🎨 Diseño responsivo para todo tipo de dispositivos  
- 🔍 Funcionalidad de búsqueda y filtrado  

## 🛠️ Tecnologías Utilizadas

- React Native  
- Expo  
- TypeScript  
- React Navigation  
- Expo Router  
- Jest (para pruebas)  

## 📋 Requisitos Previos

- Node.js (v14 o superior)  
- npm o yarn  
- Un dispositivo con [Expo Go](https://expo.dev/client) instalado o un emulador Android/iOS  

## 🔧 Instalación

1. Clona el repositorio:

git clone https://github.com/nicoCorbal/oPillsApp
cd oPillsApp


2. Instala las dependencias:

npm install
# o
yarn install


3. Inicia la aplicación:
   
npx expo start


4. Escanea el código QR con la app **Expo Go** en tu dispositivo o usa:
- `a` para emulador Android  
- `i` para emulador iOS (en macOS)  

## 🧪 Ejecutar Pruebas
